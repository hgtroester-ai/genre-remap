# Genre Remap 3.3.0 — Licensing and release documentation

This release is based on the working Genre Remap 3.2.0 build. It changes licensing, attribution, provenance and release documentation only. MIDI generation, phrase handling, fill behavior, MIDI mapping, preview playback and the 37 embedded MP3 payloads are unchanged.
